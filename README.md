# Jarvis - Simple AI Chatbot

Jarvis is a simple, beginner-friendly AI chatbot built using **HTML, CSS, and plain JavaScript**, powered by the **Google Gemini API**.

The project focuses on understanding how a frontend application can communicate with an AI API using JavaScript `fetch()` and `async/await`, while providing a clean and responsive chatbot interface.

## Features

- Chat with Google Gemini
- Continue conversations with previous messages
- Typing indicator while waiting for a response
- New Chat option
- API Key setup through the application
- Chat history stored using browser LocalStorage
- Supports formatted text and code blocks
- Friendly error messages for common API problems
- Handles network and API errors
- Responsive design for desktop and mobile devices
- Simple and beginner-friendly project structure

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Gemini API
- Fetch API
- Async/Await
- Browser LocalStorage

### No Frameworks

This project does not use:

- React
- Node.js
- Express
- Backend server
- Database

The application is built using **vanilla JavaScript** to keep the project simple and easy to understand.
